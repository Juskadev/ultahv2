# Happy Birthday Mutia Fajriah 🎂💖

Website animasi ucapan selamat ulang tahun interaktif dan romantis spesial dari **Juska** untuk **Mutia Fajriah**.

## ✨ Fitur Utama
- **Jalan Otomatis (Auto-Play Timeline)**: Pertunjukan animasi berjalan otomatis tanpa perlu repot klik dari awal.
- **Boneka Animasi Berjalan (Walking Dolls)**: Karakter chibi beruang dan kelinci yang berjalan bolak-balik di layar dengan balon dan bunga.
- **Kue Ulang Tahun 3D & Tiup Lilin**: Lilin otomatis ditiup dengan efek asap dan sorak-sorai pesta.
- **Galeri Foto Polaroid**: Menampilkan foto-foto kenangan Mutia yang anggun dan manis.
- **Surat Cinta Penuh Ketulusan**: Pesan mendalam dan doa terbaik dari Juska.
- **Kupon Cinta Pacar & Love Meter**: Hadiah kupon interaktif dan pengukur cinta hingga *Infinity (♾️)*.
- **Synthesizer Web Audio API**: Efek suara dan melodi *Happy Birthday* ala kotak musik tanpa file audio eksternal.

## 🚀 Cara Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser mana saja (Google Chrome, Microsoft Edge, Safari, dll).

Dibuat dengan segenap cinta oleh **Juska** ❤️
